1 Spreadsheet Internal (Protected)

Google Sheets disimpan di Google Drive internal BPS dengan akses tertutup (Private). Tidak ada pihak eksternal yang di-share link spreadsheet ini.

🔒 Access: Restricted to Humas BPS
2 Google Apps Script (Web App Endpoint)

Script bertindak sebagai API Proxy (Gateway). Mengubah data baris sheet menjadi format JSON, memvalidasi API Key, dan menyaring kolom sensitif.

⚡ GET script.google.com/macros/s/.../exec
3 Dashboard Frontend (Aplikasi Ini)

Aplikasi web membaca payload JSON secara aman melalui metode `fetch()`. User luar hanya melihat visualisasi grafik tanpa bisa mengedit sheet.
